# Платформа клуба «Душа. Тело. Дело» — структура

Черновик к эфиру 04.09.2026 («Вайбкодим платформу под любой ваш запрос» — Оля делает CRM).
Дорабатывается по итогам эфира, не финал. Опирается на `ARCHITECTURE.md` и `CLAUDE.md`.

---

## 1. Что это за платформа

Не образовательный конструктор общего назначения — личный кабинет под один конкретный продукт:
клуб на 3 месяца + продление. Логика ближе к CRM с доступом по оплате (как клубный VPN у ЛАБС:
залогинился, но без оплаты внутрянка не открывается), чем к GetCourse.

**Два входа:**
- **Ученица** — видит только свою программу и свой прогресс.
- **Заира (админ)** — видит всех участниц, отметки оплат, прогресс по клубу целиком.

---

## 2. Путь ученицы

1. Заявка на сайте (уже есть) → Заира вручную подтверждает оплату → аккаунт активируется.
2. Ученица получает ссылку на вход + код по SMS или email (без пароля — меньше точек отказа
   на старте, чем сброс забытого пароля).
3. Личный кабинет: программа открыта целиком с первого дня входа (так решили — не по
   расписанию, а сразу), но модули идут по порядку: Душа → Тело → Дело.
4. Каждый модуль: видео (Rutube, закрытый доступ), текст/презентация, отметка «пройдено».
5. По истечении 3 месяцев — статус «доступ активен / истёк». Если истёк — баннер с
   предложением продления за 1 900 ₽/мес (сообщество, эфиры, разборы).
6. Продлившие видят дополнительный раздел: лента еженедельных эфиров (запись + дата)
   и разборы.

## 3. Путь Заиры (админ-панель)

- Список участниц: имя, контакт, дата вступления, статус оплаты, дата окончания доступа,
  прогресс по модулям (сколько пройдено из скольки).
- Кнопка «Отметить оплату» — вручную, без автоматической интеграции с банком на старте.
  Автоматизация (ЮKassa/Продамус) — вторым шагом, когда пойдёт поток заявок.
- Кнопка «Продлить на месяц» — двигает дату окончания доступа.
- Загрузка нового эфира для продливших: ссылка на Rutube + дата + короткое описание.
- Экспорт списка участниц в CSV (для рассылок, для себя).
- Заявки с сайта падают сюда же отдельной вкладкой — то, что сейчас просто «улетает в
  никуда», потому что бэкенда для формы ещё нет.

## 4. Модули клуба (контент)

Из переписки: программа уже готова на GetCourse — видео, тексты, презентации.
Перенос: тексты/презентации копируются как есть; видео заливается на **Rutube в закрытом
режиме** (решение уже принято), в платформу вставляется только плеер по ссылке.

Три блока по методике программы:
1. **Душа** — модули под регулярность и систему (без религиозных оценок — правило уже
   зафиксировано в `CLAUDE.md` диагностики).
2. **Тело** — питание, сон, движение, энергия.
3. **Дело** — цифры, продукт, делегирование.

Внутри каждого блока — несколько уроков (точное число подтвердить у Заиры при переносе
контента с GetCourse: сколько уроков в каждом из четырёх модулей текущей программы).

## 5. Схема данных (черновик)

```
users
  id, name, contact (phone/email), role (student/admin),
  club_started_at, club_expires_at, status (active/expired/pending),
  created_at

progress
  user_id, module_id, lesson_id, completed_at

modules
  id, block (soul/body/work), title, order

lessons
  id, module_id, title, order, video_url (Rutube), content (текст/презентация), duration

payments
  id, user_id, amount, type (entry_9900 / renewal_1900), marked_by_admin_at, period_end

leads
  # то же, что уже описано в ARCHITECTURE.md для сайта — форма заявки падает сюда
  id, name, contact, comment, source, created_at, status (new/contacted/spam)

live_sessions
  id, title, rutube_url, held_at, description
  # доступны только пользователям со статусом status=active И club_expires_at пройден
  # (то есть именно продлившим, не всем подряд)
```

## 6. Что технически нужно, чего пока нет

- **Сервер** — Beget, Санкт-Петербург или Москва (подтверждено эфиром 02.09: без VPN,
  работает стабильно). До сих пор не куплен.
- **База данных** — PostgreSQL на том же сервере, без выноса на отдельный сервис (см.
  `ARCHITECTURE.md`, раздел «Семь кирпичиков»).
- **Авторизация** — код на телефон/почту, без пароля. Нужен SMS-шлюз или почтовый сервис
  для отправки кода (уточнить, есть ли уже используемый Заирой сервис рассылок —
  упоминался Notisend в контексте другого проекта).
- **GitHub** — код платформы никуда не задеплоить без репозитория. Логин так и не пришёл.

## 7. Чего сознательно НЕТ в первой версии

- Автоматической оплаты — Заира подтверждает вручную. Экономит месяц разработки,
  добавляет пять минут её времени в день на новых участниц.
- Мобильного приложения — обычный адаптивный сайт, открывается в браузере.
- Форума/чата внутри платформы — сообщество продлившихся живёт в Telegram, платформа
  только показывает ленту эфиров и открывает модули.
- Сертификатов/геймификации — не входит в обещание продукта, добавлять не по методичке
  «делать минимум, который проверяет гипотезу».

## 8. Вопросы к завтрашнему эфиру

Взять с собой на эфир, если Оля покажет что-то, что меняет план:
1. Как именно она делает gate по оплате технически — через отдельную таблицу или через
   поле статуса прямо в users (я выбрал второе — проще).
2. Стоит ли sms-код заменить на magic-link на почту (дешевле SMS, но зависит от того, что
   участницы реально проверяют).

   не светить прямую ссылку на видео в исходном коде страницы.
